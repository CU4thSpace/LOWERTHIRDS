MACROMAKER v7

Place up to four boxes on a 1920 by 1080 canvas. The tool converts pixels into ATEM position, size and crop values and writes one macro per layout.

Drag a box to move it. The white circle resizes it and keeps 16:9. The two square handles on the top corners crop it: the top-left one crops from the left and top, the top-right one from the right and top. Bottom crop is set in the fields. The dashed outline is the uncropped frame and the solid area is what stays visible. Box 3 is drawn on top.

Calibration

Import the calibration macro and run it. Camera1 should sit flush in the top-right corner of the output. Camera2 should show only the right half of its picture, along the bottom, ending at the vertical centre line. If not, adjust the position unit, flip Y, or change the crop unit until it matches. The default of 60 pixels per unit assumes the ATEM screen spans ±16 by ±9 position units.

X and Y are the top-left corner of the uncropped frame on the canvas. Crop values are in pixels of the 1920 by 1080 source.

Download the macro directly as an .xml file and import it from the ATEM Macros panel.
